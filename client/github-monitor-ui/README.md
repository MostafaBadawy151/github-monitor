# GitHub Repository Monitor: Angular UI

Angular 20 + Kendo UI for Angular (Grid, Dialog, Buttons). See the [root README](../../README.md) for the full system.

```bash
npm install
npm start          # ng serve on http://localhost:4200, /api proxied to http://localhost:5200
npm test           # Karma + Jasmine unit tests
npm run build      # production build in dist/
```
